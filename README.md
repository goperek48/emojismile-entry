One emoji, one smile — the single emoji most likely to make a stranger smile: 🤗 (hugging face). A hug is the warmest open gesture there is, instantly readable at a glance, universal across ages and backgrounds, a deliberate pick rather than the default smiley, and friendly without being intimate.

## Run it

```sh
python3 main.py
```

Writes exactly one emoji to `/output/entry.txt` — no words, no caption, no trailing newline.
